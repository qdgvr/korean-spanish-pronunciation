# Pronunciación: coreano y español

Atlas de pronunciación en español para aprender coreano.

**[Abrir la página](https://qdgvr.github.io/korean-spanish-pronunciation/)**

Pulsa una letra coreana en verde para escuchar. Las 18 consonantes con audio reproducen ejemplos con ㅡ (그, 끄, 느, 드, 뜨, 르, 므, 브, 쁘, 스, 쓰, 즈, 쯔, 츠, 크, 트, 프, 흐). Las letras españolas y los símbolos IPA sirven como referencias visuales. La tabla ofrece las vistas Seúl actual y Tradicional, combinaciones y ejemplos en contexto. En Combinaciones, la letra inicial de ㅢ se muestra sin ㅇ.

Práctica, junto a En contexto, combina cuatro tipos de ejercicios: elegir el audio de una consonante, trazar una letra, formar una sílaba a partir del audio y elegir la sílaba escuchada. La ronda mixta contiene 16 retos; cada tipo también dispone de una ronda de 12. Se comprueba la respuesta antes de continuar.

Los ejercicios de escritura incluyen 29 letras y 78 trazos. Arrastra el círculo azul siguiendo la flecha sobre la imagen gris; la parte recorrida se vuelve blanca dentro del mismo contorno. Los puntos de inicio y las flechas siguen la dirección de cada trazo. Se puede usar ratón, dedo o lápiz mediante eventos de puntero. La comprobación realizada cubrió todas las letras con ratón en navegador de escritorio; no incluye una prueba física en móvil o tableta.

La página incluye 68 archivos de audio y las 29 imágenes de escritura dentro de `index.html`. Funciona sin servicios de voz ni TTS y no requiere instalación. El archivo Excel original no se publica.
