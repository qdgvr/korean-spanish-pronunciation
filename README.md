# Pronunciación: coreano y español

Atlas de pronunciación en español para aprender coreano.

**[Abrir la página](https://qdgvr.github.io/korean-spanish-pronunciation/)**

Pulsa una letra coreana en verde para escuchar. Las letras españolas y los símbolos IPA son referencias visuales. La columna Final de En contexto no reproduce audio. En Combinaciones, Inicial muestra únicamente 의.

La página incluye 54 archivos de audio dentro de `index.html` y funciona sin servicios de voz ni TTS.

## Publicación

GitHub Pages publica la raíz de la rama `main`. No se necesita un servidor ni instalar dependencias. Para actualizar la página, sustituye `index.html` por la versión completa revisada y sube el cambio a `main`.
